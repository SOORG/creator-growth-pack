# Creator profile readiness checklist

Adapt each item to the destination platform and its actual published requirements. **Not all items apply to every creator.**

## Profile

- [ ] Handle and display name confirmed; availability checked on platform
- [ ] Bio fact-checked; meets platform character and link policies
- [ ] Avatar and banner suitable for desktop and mobile
- [ ] Contact details/CTA link tested and approved for publication

## Compliance and payments (secure operator flow only)

- [ ] Identity/KYC/KYB status confirmed if required by operator
- [ ] Tax responsibilities and required documents reviewed in secure flow
- [ ] Payment/payout eligibility verified by platform; no banking data in chat
- [ ] Current fee, payout and refund terms explicitly approved

## Products and delivery

- [ ] At least the operator-required number of actual products ready (not an invented minimum)
- [ ] Claims, filenames, supported formats and previews checked
- [ ] Product usage rights and permitted licenses verified
- [ ] Checkout and digital fulfillment tested by the operator before launch
- [ ] Public-file exposure and customer access controls reviewed where relevant

## Promotion (optional)

- [ ] Real testimonials used only with permission and evidence
- [ ] Launch posts drafted and reviewed; not claimed to be scheduled or sent
- [ ] Outreach drafts comply with opt-outs and platform rules

**Status rule:** Draft copy is not account activation. Missing required operator checks remain BLOCKED, not silently passed.
