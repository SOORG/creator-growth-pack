# Optional extensions (not shipped, not promised)

The original sales brainstorm contained a **fifth Creator Port-specific onboarding skill** and paid service tiers. Those ideas were not present as installed skill files in the uploaded archive, so this corrected v1.1.0 release deliberately includes only the four complete core skills.

Before building an optional platform onboarding integration, confirm:

- Current, approved marketplace rules for fees, payouts, refunds, discounts and affiliate commission, with version/effective date.
- Security boundaries between AI drafting and platform actions; a skill must never claim it activated an account or verified payouts without authoritative evidence.
- Identity/KYC/KYB and tax data collection through a secure approved flow, not direct disclosure to the assistant.
- Separate confirmation and authorization for create/update/publish actions, status changes and customer communications.
- Delivery security, entitlements, access controls and sandbox/staging verification.
- Legal review of the offered license, storefront terms and refund/withdrawal disclosures.

Any future bonus, pricing tier or promised consultation must be documented as an actual delivered feature before advertising it.
